Semiconductor M&A Target Screener

A machine learning project that predicts which semiconductor / analog / RF companies look like acquisition targets, based on their financial profile — and, as a stretch extension, starts on predicting whether an announced deal completes or falls through.

Built to demonstrate the kind of work described in Infineon's Strategy M&A — Asia Pacific internship posting: sourcing and joining public/commercial data, applying predictive analytics (decision trees, SVMs) to identify patterns, and using the result to inform a business/strategy decision.

The question

Given a company's financials — revenue, growth, margins, leverage, R&D intensity — can we predict whether it looks like the kind of company that gets acquired?
